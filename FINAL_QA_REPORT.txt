RUNTIME CONFIRMATION
This packaging environment cannot access the public npm registry, so the npm
packages cannot be installed and the Express/Vite services cannot be launched
here. On the presentation laptop, run start-drilldeck.bat and then
run-final-check.bat. The bundled live check creates temporary admin/trainee
data, exercises the complete workflow and removes its test records afterward.
